# Minha Lista de Tarefas (To-Do App)

Uma aplicação simples e elegante de Lista de Tarefas (To-Do List) desenvolvida com HTML, CSS e JavaScript. Este projeto permite adicionar, marcar como concluídas e remover tarefas, além de salvar os dados localmente no navegador para não perdê-los.

## 🚀 Funcionalidades

- **Adicionar Tarefas:** Insira novas tarefas na lista rapidamente.
- **Marcar como Concluída:** Clique em uma tarefa para riscá-la e marcá-la como feita.
- **Remover Tarefas:** Exclua tarefas da lista clicando no botão (`×`).
- **Persistência de Dados (LocalStorage):** O estado da lista é salvo diretamente no navegador, garantindo que as tarefas continuem lá mesmo ao recarregar ou fechar a página.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação da página e dos elementos.
- **CSS3:** Estilização da interface, incluindo o fundo em gradiente e design responsivo.
- **JavaScript (Vanilla):** Lógica principal, manipulação do DOM e integração com o `localStorage`.

## 📁 Estrutura de Arquivos

- `index.html`: Estrutura principal da aplicação.
- `style.css`: Estilos visuais e layout.
- `script.js`: Lógica de adicionar, remover, concluir tarefas e salvar os dados.
